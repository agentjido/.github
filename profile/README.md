# Jido

Build autonomous agents with Elixir and OTP.

Jido is an open-source framework for building agents and workflows in Elixir. It provides a core agent runtime, actions, and signals. You can add AI and other integrations when you need them.

## Get started

- [Visit jido.run](https://jido.run)
- [Read the Jido guide and docs](https://github.com/agentjido/jido#documentation)
- [View all repositories](https://github.com/orgs/agentjido/repositories)

## Core projects

- [jido](https://github.com/agentjido/jido) — Core agent framework and runtime
- [jido_action](https://github.com/agentjido/jido_action) — Composable, validated actions
- [jido_signal](https://github.com/agentjido/jido_signal) — Signals and message routing
- [jido_ai](https://github.com/agentjido/jido_ai) — AI and LLM features for Jido agents
- [req_llm](https://github.com/agentjido/req_llm) — Elixir library for LLM APIs

## Chat projects

- [jido_chat](https://github.com/agentjido/jido_chat) — Chat models and adapter contracts
- [jido_messaging](https://github.com/agentjido/jido_messaging) — Messaging runtime and delivery
- [jido_chat_telegram](https://github.com/agentjido/jido_chat_telegram) — Telegram adapter
- [jido_chat_discord](https://github.com/agentjido/jido_chat_discord) — Discord adapter
